## Local checks

`npm test` covers the original 17 workflow cases plus replay checkpoints for capture/void/refund, question editing/freezing, task-linked correction persistence, real media decoding failures, malformed model output, and printable evidence delivery. `npm run build` checks the production React bundle. Coordinator browser checks are separate evidence, not implied by these tests.

`eval/results-local.json` records **8 cases, 14/14 concern terms retained, versus 1/14 in the fixed four-task baseline**, and zero unsupported listing quotes under the exact-substring metric. This demonstrates lossless concern retention, **not improved model quality**: both compared paths were deterministic, no provider was called, semantic relevance and human edit time were not measured. Exclusions count as represented when explicitly documented; they are not evidence deliverables.

## Source basis

The model adapter retains strict `text.format` schema output plus application-level validation, following [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs). These documents guide implementation; neither proves account-backed execution.
